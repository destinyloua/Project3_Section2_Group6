# SWAMP-Greenhouse

Welcome to our Greenhouse Manager: SWAMP
  "Sustainable Water Application for Managing Plants"

Created by Aiden, Destiny, Liam and Tyler 

This application was written and tested in C++, with a colourful and interactive GUI created with RayLib. It is a simple control panel that simulates how the environment within a greenhouse can change over time. This project was a collaborative effort developed in the fall 2024 term.
